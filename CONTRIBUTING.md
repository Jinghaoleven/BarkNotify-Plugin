# Contributing

Use Python 3.11+ for the main plugin and Python 3.9+ for the optional tunnel. Discuss large changes in an issue first; fixes can be submitted directly with a clear before/after description.

See [development](docs/development.md) for tests and [releasing](docs/releasing.md) for artifact checks. Keep public defaults independent of personal hosts and tools. Preserve saved settings and unrelated Codex/SSH configuration. Use disposable test keys and mock servers.

User documentation should cover actions and expected outcomes. Keep compatibility and implementation details in development documents.
